Copilot Extensions for Eclipse

This is a p2 update site for the companion plugin that adds multiple chat sessions and extra MCP integrations to GitHub Copilot for Eclipse.

Install

  1. Install GitHub Copilot (0.19.0 or later).
  2. In Eclipse, open Help → Install New Software…
  3. Add this site and install Copilot Extensions:
https://philipp0205.github.io/copilot-eclipse-extensions/

Source and issues: github.com/Philipp0205/copilot-eclipse-extensions
